# ClipMini 公网中转（预备实现，尚未部署）

同一 Wi-Fi 请直接使用 ClipMini 内置的“创建局域网房间”，不需要此服务。

此服务为后续公网联机准备，兼容客户端协议 v2（ClipMini 1.45 起）。只转发八种信号、心之钢、屏幕比例坐标和昵称，不传截图、剪贴板或 AI 内容。房间最多 10 人，随机 8 位邀请码，24 小时过期；空房间保留 2 分钟供断线重入。消息不落盘，不补发离线信号。每人每秒最多 2 条信号。

## 本地运行

需要 Python 3.11 或更高版本：

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python server.py
```

默认仅监听 `127.0.0.1:8765`。公网部署时由 HTTPS 反向代理暴露 WSS，内部保持环回监听。平台容器部署可通过 `HOST=0.0.0.0` 和 `PORT` 指定监听地址。

房间码相当于邀请凭据，仅分享给朋友。服务能看到昵称和信号，没有端到端加密。公网部署需要补上反向代理层的连接/IP 限速及 TLS；本轮没有部署、购买服务器或配置域名。

## 验证

```sh
.venv/bin/python -m unittest discover -s . -v
```

测试覆盖房间隔离、成员退出重入、身份由服务端确定、十人上限、非法信号、重复消息和频率限制。
