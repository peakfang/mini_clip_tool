# ClipMini

macOS 菜单栏桌面信号工具，支持 LOL 标记、心之钢和局域网联机，并附带剪贴板历史。

## 下载与安装

[下载 ClipMini 1.48（Apple Silicon）](https://github.com/peakfang/mini_clip_tool/releases/download/v1.48/ClipMini-1.48-menu.zip) · [发布页](https://github.com/peakfang/mini_clip_tool/releases/tag/v1.48)

需要 M 系列芯片 Mac、macOS 13 或以上。更新前退出旧版，解压后将 `ClipMini.app` 放入“应用程序”并打开，从菜单栏问号进入设置。

## 桌面信号与心之钢

- 按住 **Control + Option** 呼出轮盘，移动鼠标选择，松开任一快捷键或点击左键确认。
- 鼠标停在中心约 1.4 秒蓄满心之钢，点击释放音效和当前显示器的全屏冲击；中心松开快捷键、按 Esc 或右键取消。
- 最多同时显示 30 个标记，各自自动消失；心之钢全屏冲击有 2 秒间隔。
- 菜单支持关闭桌面信号、静音、试听音效和登录时启动。

## 局域网联机

1. 连接可互通的局域网，打开“联机房间…”，填写昵称。
2. 一人创建房间，朋友从房间列表加入，也可通过复制、粘贴邀请加入。
3. 最多 10 人，同步普通标记、心之钢释放及本次入房的叠钢次数，支持暂停接收。

标记按屏幕比例映射到接收方鼠标所在的显示器，适配不同分辨率；不会识别两台电脑上的窗口内容。重新入房后次数清零，房主退出会关闭房间，断线后需重新加入。

房间页可读取 Wi-Fi 名称，可能需要定位权限。首次联机请允许本地网络与防火墙访问；访客隔离或组播限制可能影响连接。目前安装包使用局域网联机。

## AI 请求支援

选择“请求支援”截取前台应用窗口，在本机预览后，可以复制截图并打开 ChatGPT 手动粘贴发送，或交给已安装、已登录的本机 Codex 分析。

截图需要屏幕录制权限，Codex 分析可能消耗账号额度。发送前请检查敏感内容；截图不会随房间标记广播。

## 剪贴板

菜单栏“剪贴板”聚合查看历史、面板位置与清空历史入口。

- **Control + X** 打开历史，保存文字、图片和文件，最多 50 条。
- 支持搜索、单条删除、左右选择和回车粘贴，按 Esc 关闭。
- 可选底部面板或菜单栏下方面板，自动粘贴需要辅助功能权限。

历史保存在本机 `~/Library/Application Support/ClipMini/`。复制过的密码、验证码等内容也可能被记录，可随时清空。

## 从源码构建

安装 Xcode 及命令行工具后执行：

```bash
chmod +x build-app.sh
./build-app.sh
```

生成应用位于 `outputs/ClipMini.app`，局域网中转已内置，无需额外部署。
